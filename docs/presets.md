# プリセット

プリセットは図形、配置、イージング、各パラメータの反応先、回転速度、ゲインを決める。個数、サイズ、色、線幅、透明度、シード、BPM、オフセット、感度、拡大、回転、移動、減衰、強拍強調はトラックバーの値が常に優先される。

カスタムを選ぶと、図形、配置、イージング、反応先のリストが有効になる。名前付きプリセットでは、それらのリストは隠れる。

| プリセット | 内容 |
| --- | --- |
| Beat Burst | 混合図形をばらまき、打音で拡大と透明度が跳ねる |
| Geometric Orbit | 円を円周に並べ、低音で大きさが変わり、一定速度で回転する |
| Rhythm Grid | 四角を格子に並べ、拍と小節頭で動く |
| Bass Pulse | 円を放射状に置き、低音で膨張する |
| Minimal Motion | 三角の格子を、小さい係数で拍に合わせる |

新しいプリセットを足すときは `script/RhythmShapes/rs_preset.lua` の `profiles` と `names` に項目を追加し、`RhythmShapes.obj2` の `--select@preset` に同じ番号を追加する。番号は 0 がカスタムである。必須キーは `required_keys` にある。追加したら `lua5.1 tests/run.lua` を実行する。
