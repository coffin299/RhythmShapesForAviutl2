# モーション

駆動量は、そのフレームのシーン時刻、BPM、音声窓から計算する。前のフレームの座標には足さない。

シーン時刻は `(obj.frame_s + obj.frame) / obj.framerate` である。BPMリストの `start` と `offset` も秒として、この時刻と比べる。リストが空のとき、または手動BPMのときは、設定した BPM とオフセットを使う。オフセットの単位はミリ秒で、拍を前後にずらす。

拍の分割は 1、2、4、8。強拍は小節内の先頭の拍で、強拍強調が駆動量を増やす。

反応先は次のいずれかである。

| 設定 | 動き |
| --- | --- |
| 拍 | 分割した拍の頭から減衰する |
| 強拍 | 小節頭だけ反応する |
| 音量 | 窓全体の RMS |
| 低音 / 中音 / 高音 | 帯域エネルギー |
| 打音 | 検出ピークからの減衰 |

イージングは linear、outQuad、outCubic、outExpo。減衰時間に達すると駆動量は 0 になる。

図形ごとの時間差は、拍周期を個数で割った固定オフセットである。移動は中心から外向きで、画面外には出ないように位置を制限する。プリセットの `gain` はトラックバーの拡大・回転・移動に掛かる係数で、Minimal Motion だけ 0.35 にして同じトラック値でも動きを小さくする。Geometric Orbit は `spin_dps` により時刻に比例して回転する。

表示数を打音に追従させるプリセットでは、駆動量が 0 のときも個数の 30% は残す。透明度はトラック値の 20% を残し、駆動量でそこから 100% まで上げる。無音でも図形の配置が分かるようにするためである。
