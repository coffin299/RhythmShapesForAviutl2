# 音声解析とビート検出

## 取得

`obj.getaudio` には時刻引数がない。2.1.14 の `lua.txt` では、オブジェクト時間を基準にした位置のデータを返すとだけ書かれている。実装は毎フレーム、現在位置の PCM を最大 8192 サンプル、フーリエを 1024 ビン取得する。前フレームの値は保存しない。シーク後も同じ時刻なら同じ窓を読み、同じ結果になる。

PCM は 16bit スケールとして 32768 で割る。値が取れないときは音量 0 として、BPM グリッド側の動きは続ける。

## 周波数

公式フーリエは、元のサンプリング周波数の 1/2048 から 1/2 まで、1/2048 刻みの 1024 個である。ビン `i`（1始まり）の周波数は `rate * i / 2048` として帯域を切る。

- 低音: 20–250 Hz
- 中音: 250–2000 Hz
- 高音: 2000 Hz からナイキストまで

絶対値が 4 を超える列は 16bit スケールとみなして 32768 で割る。フーリエが空のときだけ `spectrum` を使う。そのビンが 0 Hz からナイキストまで等間隔だという記載は `lua.txt` にないため、これはフォールバックの仮定である。どちらも無いときは PCM のローパスで低音を近似する。

## 打音

窓を約 10 ms の RMS に分け、立ち上がりがしきい値を超えたホップを打音候補にする。しきい値は窓内の平均と検出感度から決める。感度が高いほどしきい値は下がる。

後半のホップには、前半との低域差、RMS 差、64 点 DFT のスペクトルフラックスを重み付きで足す。最小間隔より近い候補は、早い方だけを残す。大きい音が続いているだけでは立ち上がりが無いので、連続しては発火しない。

発火からの時間は、窓の末尾とピーク位置の差である。減衰はこの時間だけで決まる。

## BPM推定

包絡の自己相関から 70–180 BPM を推定し、`estimated_bpm` と `bpm_confidence` に入れる。信頼度が 0.55 未満、窓が短すぎる、包絡が平坦なときは推定値を出さない。

この推定は打音とは別の情報で、アニメーションには使わない。8192 サンプルは 48 kHz で約 0.17 秒しかなく、拍の周期を安定して測れない。長いテスト信号では 120 BPM 前後を返せるが、実時間のプレビューでは信頼度が低いことが多い。拍に合わせるときは BPM グリッドか手動 BPM を使う。
